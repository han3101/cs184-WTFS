## Goal

Replace `Field2D::fillUniform` stub with a real D2Q9 Lattice Boltzmann step while keeping every file from Phase 0a/0b intact. Tracers keep sampling `Field2D.ux/uy` with bilinear interpolation — they just see a now-non-uniform velocity field. Viewer keeps the same `drawField/drawTracers/drawObstacles` API.

Outcome: `./cyl2d_batch --re 100` reproduces the A3 targets that plan.md defines as the 0c gate, and `./tracers2d_live --uniform` still passes Gate 0b (no regression).

- WGSL buffer-limit concerns (128–256 MiB) apply to Project 3 only; not a constraint for 0c, but 0c layout choices must not preclude the 4-buffer split later.
- Do not fix PBF bugs in `legacy-pbf/` (plan.md § Non-goals).
- Do not add 3D LBM kernels, `voxelize.h` for car OBJ, or `tunnel3d` in 0c beyond 3D indexing constant reuse. 3D is Phase B after A3 passes. `cavity2d` and `tunnel3d` are not 0c deliverables, though `Field3D` helpers already exist.
- Do not introduce new dependencies beyond header-only `stb_image_write` if needed for PNG. No FetchContent for core solver.

## Key Decisions

1. **D2Q9 only in 0c, D3Q19 constants but no kernels.** 2D is the fast iteration loop; 3D indexing already proven in `Field3D`. Shipping 3D LBM now would add untested memory layout work with no validation target until B1. Tradeoff: defers `voxelize.h`/`obj.h` to Phase B.

2. **SoA ping-pong `f, f_next` inside `Field2D`, not a separate Lattice class.** Keeps `apps/tracers2d_*` diff minimal (`field.fillUniform` → `field.initEquilibrium` + `lbm.step(field)`). Alternative separate `Lattice` owning `f` would duplicate `nx,ny,idx` helpers. Chosen to minimize churn and keep `field.h` as single source of truth for indexing.

3. **Pull streaming, BGK, double-buffer.** Pull (`f_new[q][idx]=f_old[q][idx−c_q]`) maps directly to WGSL gather per plan.md rationale. BGK is simplest collision; τ>0.51 assert catches Re too high for this resolution. MRT/TRT deferred to Phase E where BGK destabilizes.

4. **Boundaries: Zou-He inlet (velocityDirichlet) + zero-gradient outlet + mid-grid bounce-back on solidMask.** Simpler than regularized inlet and avoids fixing outlet pressure. Solid mask built from existing `obstacle.h` SDF (`sdf<0`) so `--circle/--block` flags keep working without a new voxelizer.

5. **Probes: momentum-exchange for drag + wake probe FFT for Strouhal.** Matches plan.md A3 gate (St, Cd) and reuses existing `Field2D.ux/uy` sampling for probe. `io.h` adds CSV/raw dump for `cyl2d_batch --compare` used later by gpu-lbm.

## Recommended Approach

Evolve the uniform stub in place:

- Add `lattice.h` first — no deps, validates weights/opposites invariants before any step logic.
- Expand `units.h` to full conversion with `Units { u_lb, nu_lb, tau, dx, dt }` helpers and docs/units.md update.
- Upgrade `field.h` to own `f, f_next` plus `solidMask`; keep `ux,uy` as macroscopic caches. Add `initEquilibrium(u0)` that fills `f` with `feq(ρ=1, u)`.
- Implement `lbm.h/.cpp` stateless functions operating on `Field2D &`: `macroscopic()`, `equilibrium()`, `collideAndStream()` (fused to avoid extra pass) with double-buffer swap, then `applyBoundaries()`.
- `boundary.h` owns Zou-He and bounce-back; `obstacleMaskFromSDF(field, obstacles)` is a free function so tracers' SDF logic stays visual-only.
- Keep `tracers.*` unchanged except removing active slip/bounce path — `Passive` becomes the only mode when `solidMask` is present; otherwise 0a behavior preserved behind `--uniform`.
- `apps/cyl2d_batch` (batch CSV) and `apps/cyl2d_live` (viewer loop calling `lbm.step()` once per frame, interpolating tracers with `dt` substeps if needed) both share `lbm` — one for CI, one for visual gate.
- Validation ladder: unit tests → Poiseuille (fastest bug detector per plan.md A1) → lid-cavity → cylinder Re=100. Run A1/A2 as regression after A3 passes if 0c was validated directly against A3.

## Risks / Rollback

- **τ instability:** Re too high for chosen `nx` pushes `tau→0.5` and BGK diverges (plan.md § Unit system). Mitigation: assert `tau>0.51` and gate Re=100 at 400×80 (τ≈0.55) first; higher Re requires larger `L_lb` (resolution ladder).
- **Bounce-back vs SDF mismatch:** Visual obstacle (tracer SDF) and fluid obstacle (solidMask) must agree. Build mask from same `Obstacle` SDF to keep single source of truth; test B2 mask-vs-analytic in Phase B.
- **Pull-stream off-by-one at outlet:** Zero-gradient outlet needs one-cell ghost logic; otherwise wake wraps. Validate with A1 Poiseuille gradient check.
- **Performance:** 2D `400×80×9≈1.15M` floats ≈4.6 MB per buffer, trivial; no rollback needed. Ping-pong swap is pointer/bulk copy — start with vector swap.
- **Rollback:** Keep `--uniform` path in `cyl2d_live`; if LBM step fails, CI still green via `tracers2d_headless --uniform`. Revert is removing `lbm` call and `solidMask` build — no schema change to `tracers` persistence.
